# Block Fighter（仮）

ロブロックス風の低コストテクスチャで作る格闘ゲームの土台。

## 起動

```bash
npm install
npm run dev
```

## 現在の内容: ステージ土台

- **草原の床**: 64×64 の島（上面 y=0）。上面は緑、側面は土色の単色
- **石の壁**: 外周に、大きさ・向き・傾きがバラバラな石ブロックを重ねて積んだ乱雑な壁
- **海**: 外側一面の単色の平面

## 操作

| キー | 動き |
| --- | --- |
| WASD / 矢印 | 移動（カメラの向き基準） |
| Shift | 走る |
| Space | ジャンプ |
| 左クリック / J | 攻撃。押し続ける（または連打する）と 袈裟斬り → 横薙ぎ → 跳び込み兜割り を繰り返す |
| F | 立ちポーズ ⇔ 構えポーズ |
| 右ドラッグ / ホイール | カメラ回転 / ズーム |

### スマホ（横画面）

| 操作 | 動き |
| --- | --- |
| 左半分に触れてスライド | スティック（触れた場所に出る）。倒した量で歩く速さが変わり、外周まで振り切ると走る（輪がオレンジ色になり RUN と表示） |
| 右下の剣ボタン | 攻撃。押し続けると連続斬り |
| それ以外をドラッグ / 2本指 | カメラ回転 / ズーム |

縦向きのときは「横向きにしてください」と表示する。タッチ操作の端末で自動表示され、PC では画面に触れたときだけ出る。

## キャラ

- すべて単色の箱。肌は白、体型は細身（胴幅1.6・腕0.6・脚0.72、身長 約4.95 × scale 0.15）
- 顔は透過キャンバスに描いた絵を頭の正面に1枚貼るだけ（`smile` / `angry`）
- 髪型は箱の組み合わせ（`short` / `spiky` / `none`）、袖は `short` / `long`
- 関節は首・腰・肩×2・肘×2・手首×2・股×2・膝×2・足首×2（＋骨盤の移動と回転）
- 曲げたときに隙間が開かないよう、子パーツを親の中へ少し伸ばしてある

### モーション

`src/character/poses.js` に、全関節の角度を返す関数として定義。

| 名前 | 内容 |
| --- | --- |
| `stand` | 立ちポーズ。呼吸、左右へのゆっくりした体重移動、視線の動き |
| `fight` | 構えポーズ。半身、前手と後手、後ろ足のかかとを浮かせて小さく弾む |
| `walk` | かかと着地 → 靴底を地面に → つま先で蹴り出し。骨盤と胸の逆ひねり、腕振り |
| `run` | 前傾、もも上げ、かかとの引きつけ、肘を曲げた腕振り、両足が浮く滞空 |
| `crouch` → `air` → `land` | ジャンプ。ため → 伸び上がり → 頂点で膝を抱える → 足を伸ばして落下 → 沈み込んで着地 |

| `attack1` → `attack2` → `attack3` | 剣の3連撃（ループ）。振りかぶり → 斬る瞬間 → 振り抜き → 残心 |
| `hit` | 被弾。のけぞって持ち直す |

- 歩き・走りの周期は移動距離に同期（足が滑って見えない）
- 接地中は靴底の位置から腰の高さを毎フレーム決める（足のめり込み・浮きを防ぐ）
- モーションの切り替えは今の姿勢からなめらかに補間

## 剣と攻撃

- 剣は箱と三角の切っ先だけの西洋剣（刃・樋・十字の鍔・革巻きの柄・柄頭）。右手首の関節に握らせている
- 剣を持っているときは、立ち・構え・歩き・走りで右腕の持ち方が変わる（`poses.js` の `carrySword`）
- 攻撃は `Controller.js` の `ATTACKS` で長さ・当たる区間・つなぎのタイミング・踏み込みを設定
- 攻撃を出した瞬間、近くの相手へ自動で向き直り、剣が届く間合いまで踏み込む
- 当たり判定は刃（根元〜先端）と相手の体の距離。振っている間は1フレームを5分割して取りこぼしを防ぐ
- 振っている間は剣の軌跡（半透明の帯）が出る

### 手応えの演出（`src/camera/CameraFx.js` ほか）

| 場面 | 演出 |
| --- | --- |
| 振った瞬間 | 斬る方向へカメラが振られ、画面が少し傾き、視野が一瞬広がる |
| 命中 | 時間がほぼ止まる（ヒットストップ）、画面揺れ、視野がぐっと寄る、相手が白く光る、火花、のけぞりと吹き飛び |
| 3撃目 | 跳び上がりでカメラが引き、着地で揺れる。命中時の演出はすべて強め |
| 常時 | カメラは P1 を少し遅れて追う（踏み込みや走りの勢いが出る） |

カメラ演出は OrbitControls の結果に描画の直前だけ上乗せして、描画後に元へ戻している。

テクスチャ画像は使わず、単色のマテリアルだけで構成（ロブロックス風）。
石の配置は `seed` で決まるので、同じシードなら毎回同じ壁になる。

| `src/character/Controller.js` | 移動・ジャンプの物理とモーション切り替え、速さなどの設定 |
| `src/character/Sword.js` | 剣のモデル |
| `src/effects/SwordTrail.js` | 剣の軌跡 |
| `src/effects/Sparks.js` | 命中時の火花 |
| `src/camera/CameraFx.js` | カメラの振り・傾き・ズーム・揺れ |
| `src/input.js` | キーボード・マウス入力 |

| `src/main.js` | レンダラー・カメラ・ライト・ループ |
