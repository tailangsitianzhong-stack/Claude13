# Block Fighter（仮）

ロブロックス風の低コストテクスチャで作る格闘ゲームの土台。

## 起動

```bash
npm install
npm run dev
```

## 現在の内容: ステージ土台

- **草原の床**: 64×64 の島（上面 y=0）。上面は緑、側面は土色の単色
- **石の壁**: 外周に、大きさ・向き・傾きがバラバラな石ブロックを重ねて積んだ乱雑な壁
- **海**: 外側一面の単色の平面

### 公開（GitHub Pages など）

ビルドなしで、リポジトリの中身をそのまま配信しても動く。`index.html` が同梱の
`vendor/three.module.min.js` を import map で読み込むため（Safari は 16.4 以降）。
`npm run build` した `dist` を配信してもよい。

## 操作

| キー | 動き |
| --- | --- |
| WASD / 矢印 | 移動（画面の奥が前。視点の向きが基準） |
| Shift | 走る |
| Space | ジャンプ。空中で攻撃を押すと叩きつけ（範囲攻撃）。3段目を当てた直後に押すとコンボ技（掴み上げ） |
| 左クリック / J | 攻撃。押し続ける（または連打する）と 袈裟斬り → 横薙ぎ → 跳び込み兜割り を繰り返す。移動しながらでも止まらず、キャラが向いている方向へ斬る |
| K / E | スキル1（剣投げ）。使うと6秒のクールタイム。使ったあとはスキル3（ため斬り）に変わり、長押しでためる |
| L / Q | スキル2（地割れ）。使うと8秒のクールタイム。使い終えるとスキル4（突進）に変わる |
| F | 立ちポーズ ⇔ 構えポーズ |
| 右ドラッグ / ホイール | 視点を回す / 距離を変える |

### スマホ（横画面）

| 操作 | 動き |
| --- | --- |
| 左半分に触れてスライド | スティック（触れた場所に出る）。倒した量で歩く速さが変わり、外周まで振り切ると走る（輪がオレンジ色になり RUN と表示） |
| 右下の剣ボタン（赤） | 攻撃。押し続けると連続斬り。空中で押すと叩きつけ |
| その左の矢印ボタン（青・一回り小さい） | ジャンプ。通常攻撃の3段目を当てると1秒だけ金色の「掴み」ボタンに変わり、押すとコンボ技 |
| 攻撃ボタンの真上のボタン（紫・ジャンプと同じ大きさ） | スキル1（剣投げ）。使うと水色のスキル3（ため斬り）に変わる。スキル3を使うとスキル1に戻り、クールタイムの残り秒数を表示 |
| 攻撃ボタンの左斜め上のボタン（橙・同じ大きさ） | スキル2（地割れ）。使い終えるとピンクのスキル4（突進）に変わる。スキル4を使うとスキル2に戻り、クールタイムの残り秒数を表示 |
| それ以外をドラッグ | 視点を回す（スティックや攻撃と同時に操作できる） |

縦向きのときは「横向きにしてください」と表示する。ダブルタップやピンチでの拡大、長押しでの文字選択・メニューは無効にしてある。タッチ操作の端末で自動表示され、PC では画面に触れたときだけ出る。

## 闘技場の壁

壁の石は傾けて乱雑に積んでいるため、そのままだと内側へ張り出してキャラやカメラが石に入る。
そこで、各石の内側の面が `wallInner`（床の端から壁の厚み分だけ内側）より内へ入らないよう、積んだあとに外へずらしている（`Stage.js`）。
キャラが動ける範囲（`bounds`）は、石の内側の面より手前に収まる。

## 視点

三人称の追従カメラ（`src/camera/ThirdPersonCamera.js`）。キャラの後方・頭より少し上から背中越しに見る。

- 視点と移動は分離: 移動してもカメラの向きは変わらず、視点操作でキャラは動かない
- 移動は視点の向きが基準（前に倒すと画面の奥へ進み、キャラはその方向を向く）
- カメラは、注視点から後ろへ伸ばした「腕」を縮めて、壁の内側の面（`stage.cameraBounds`）の手前に収める。壁際でカメラが石に入ったり、キャラの頭に押し込まれたりしない
- 距離・高さ・見下ろす角度・追従の遅れは同ファイルの先頭で調整できる

## キャラ

- すべて単色の箱。肌は白、体型は細身（胴幅1.6・腕0.6・脚0.72、身長 約4.95 × scale 0.15）
- 顔は透過キャンバスに描いた絵を頭の正面に1枚貼るだけ（`smile` / `angry`）
- 髪型は箱の組み合わせ（`short` / `spiky` / `none`）、袖は `short` / `long`
- 関節は首・腰・肩×2・肘×2・手首×2・股×2・膝×2・足首×2（＋骨盤の移動と回転）
- 曲げたときに隙間が開かないよう、子パーツを親の中へ少し伸ばしてある

### モーション

`src/character/poses.js` に、全関節の角度を返す関数として定義。

| 名前 | 内容 |
| --- | --- |
| `stand` | 立ちポーズ。呼吸、左右へのゆっくりした体重移動、視線の動き |
| `fight` | 構えポーズ。半身、前手と後手、後ろ足のかかとを浮かせて小さく弾む |
| `walk` | かかと着地 → 靴底を地面に → つま先で蹴り出し。骨盤と胸の逆ひねり、腕振り |
| `run` | 前傾、もも上げ、かかとの引きつけ、肘を曲げた腕振り、両足が浮く滞空 |
| `crouch` → `air` → `land` | ジャンプ。ため → 伸び上がり → 頂点で膝を抱える → 足を伸ばして落下 → 沈み込んで着地 |

| `attack1` → `attack2` → `attack3` | 剣の3連撃（ループ）。振りかぶり → 斬る瞬間 → 振り抜き → 残心 |
| `airSlam` | 空中攻撃。剣を頭上へ振りかぶり、切っ先を下にして前方へ突っ込む。着地後は `attack3` の着地〜残心へつながる |
| `grab` → `liftCrouch` → `carry` → `throw` | コンボ技の自分側。掴む → 沈み込んでためる → 掲げて跳ぶ → 振りかぶって投げ落とす |
| `struggle` → `thrown` → `down` | コンボ技の相手側。もがく（両手で相手の腕を掴み、足をばたつかせ、首を振り、体をよじる）→ 手足をばたつかせて落ちる → 倒れる |
| `brake` | 急停止。前足を突っ張り、腕を広げてバランスを取る |
| `spinUp` → `throwSword` → `beckon` → `flurry` → `pullOut` → `kick` | スキル1の自分側。振り回す → 投げる → かざして引く → 連打 → 引き抜く → 蹴る |
| `impaled` → `dragged` → `pummeled` | スキル1の相手側。刺さってよろめく → 引きずられる → 連打を浴びる |
| `chargeStance` | スキル3のため。剣を右脇に引いて構える（放つときは通常攻撃の振りを素早く使う） |
| `stunned` | 気絶。ふらふらと揺れ、首がぐらつき、膝が抜けかける |
| `lungeAim` → `lungeDash` → `lungeStrike` | スキル4。剣を前へ向けて構える → 水平に寝て飛びかかる → 突きの姿勢で止まる |
| `groundStab` → `stabCharge` → `stabPull` | スキル2。振り上げて突き刺す → 膝をついて力を込める → 引き抜いて立つ |
| `hit` | 被弾。のけぞって持ち直す |

- 歩き・走りの周期は移動距離に同期（足が滑って見えない）
- 接地中は靴底の位置から腰の高さを毎フレーム決める（足のめり込み・浮きを防ぐ）
- モーションの切り替えは今の姿勢からなめらかに補間
- 慣性の傾き: 走り出しは前のめり、止まるとのけぞって揺り戻し、曲がるときは内側へ倒れる（どのモーションにも重なる）
- 走りから入力を離すと、足を突っ張って少し滑ってから止まる（`brake`。足元に土煙）
- 攻撃・着地・急停止のあとは、ゆっくり構え直して少し揺り戻してから立ちに戻る

## 剣と攻撃

- 剣は箱と三角の切っ先だけの西洋剣（刃・樋・十字の鍔・革巻きの柄・柄頭）。右手首の関節に握らせている
- 剣を持っているときは、立ち・構え・歩き・走りで右腕の持ち方が変わる（`poses.js` の `carrySword`）
- 攻撃は `Controller.js` の `ATTACKS` で長さ・当たる区間・つなぎのタイミング・踏み込みを設定
- 攻撃を出した瞬間、近くの相手へ自動で向き直り、剣が届く間合いまで踏み込む
- 当たり判定は刃（根元〜先端）と相手の体の距離。振っている間は1フレームを5分割して取りこぼしを防ぐ
- 攻撃中は刃を包む光のオーラが剣より長く伸び、その先端までが攻撃範囲になる（`Sword.js` の `AURA.end`。剣だけのときの約1.5倍）
- 振っている間は剣の軌跡（水色の光の帯）が出る

### 空中攻撃（叩きつけ）

ジャンプ中に攻撃を押すと、前方斜め下へ一瞬（約0.1秒）で突っ込み、剣で地面を叩く。
入力していればその方向へ、近くに相手がいればその手前へ着地する。
着地した瞬間、剣が叩いた地点を中心とした円の中にいる相手に命中する範囲攻撃（強攻撃扱い）。
叩いた地面はへこんでひびが入り、まわりの地面がめくれ上がる（約2秒で元に戻る。見た目だけで床の形は変わらない）。
一度出すと、着地から0.8秒は出せない（クールタイム）。
突っ込む距離・速さ・範囲・クールタイムは `Controller.js` の `AIR_SLAM` で設定。着地後は攻撃を押し続けると地上の連続斬りへつながる。

### コンボ技（掴み上げ）

通常攻撃の3段目（跳び込み兜割り）を当てると、1秒だけ受け付ける。その間にジャンプを押すと発動。

1. 一瞬で間合いを詰め、左手で相手の胸ぐらを掴む（相手はもがき続ける）
2. 掴んだまま沈み込んで力をため、相手を掲げて身長の約3倍の高さまで跳び上がる
3. 頂点で相手を前方の地面へ投げ落とす（相手は背中から激突して倒れる）
4. 倒れた相手へ、剣で叩きつける（通常の叩きつけより強く吹き飛ばす）

発動中は操作できず、カメラは引いて2人を映す。受付時間・高さ・各段階の長さは `Controller.js` の `FINISHER` で設定。
時間切れ、または相手が離れすぎているときは、ただのジャンプになる。

### スキル1（剣投げ）

地上で使える。全体で約5秒（ヒットストップ込み）。押してから剣が刺さるまでは約0.7秒。

1. 剣を頭上で素早く振り回す
2. 相手へ投げる。剣は縦に回転しながら飛び、相手の胸に刺さる
3. 左手をかざすと光の綱がつながり、刺さった剣ごと相手を宙に引きずって手元へ引き寄せる
4. 両手で連打（毎秒 約7発、だんだん速く。計13発前後）。1発ごとに相手の頭と上体が弾かれる
5. 柄を握ってためてから、体をひねって剣を引き抜く
6. 右足で蹴り飛ばす（一番強い吹き飛ばし）

発動中は操作できない。相手が遠すぎる（身長の約9倍より先）ときは前方へ投げ、剣が回りながら手元に戻って終わる。
各段階の長さ・連打の速さ・クールタイムは `Controller.js` の `SKILL1` で設定。

### スキル3（ため斬り）

スキル1を使うと、同じボタンがスキル3に変わる（スキル3を使うとスキル1に戻る）。

- ボタンを押している間、剣を右脇に引いて構え、力をためる（最大2秒）。ためるほど深く沈み、剣の光が強くなる
- 途中で離すと、飛ぶ斬撃を1つ放つ。ためた分だけ斬撃が大きく、強くなる
- 最大までためると、自動で斬撃を3つ続けて放つ（袈裟・横・縦。3つ目が一番強い）
- ため中は移動できないが、向きは変えられる。近くに相手がいれば自動でそちらを向く

斬撃は身長の約27倍先まで飛び（闘技場の端まで届く）、見た目の大きさと当たり判定は初期の3倍。ためる時間・速さ・距離・大きさは `Controller.js` の `SKILL3` で設定。

### スキル4（突進）

スキル2を使い終えると、スキル2のボタンがスキル4に変わる（使うとスキル2に戻る。スキル3と同じ仕組み）。
地上で使える。全体で約1.1秒。

1. 剣を相手へまっすぐ向けて、体を低く沈めて構える（約0.3秒。この間も相手を狙い続ける）
2. 一瞬（約0.09秒）で飛びかかる。相手がいれば、その手前まで（最大で身長の約12倍）。通り道に光の線と火花が走る
3. 突きの姿勢で止まり、命中すると相手を遠くまで吹き飛ばす（約45〜50リグ = 身長の約10倍）。相手は背中から飛び、倒れたまま滑る
4. 構え直す

相手が闘技場の壁に当たると、激突の演出が出る。
カメラは相手の方へ動かない。飛びかかっている間は追従を止め、終わってからゆっくり自分に追いつく。
各段階の長さ・距離・吹き飛ばす強さは `Controller.js` の `SKILL4` で設定。

### 状態異常（気絶）

状態異常は `src/character/StatusEffects.js` の「枠」で管理する。キャラごとに1つ持ち、種類ごとに残り時間を数える。
新しい状態異常は `STATUS_DEFS` に1行足し、効果の中身を `has(name)` で判定して作る。表示枠（`src/ui/StatusHud.js`）は自動で対応する。

- **気絶**（`stun`）: スキル2を当てた相手に4秒付く。その間は何も入力できず、ふらふら立ったまま（`stunned` ポーズ）、頭上を星が回る
- 相手にかかっている状態異常は、画面上部の中央に「種類・残り時間バー・残り秒数」で表示する

### スキル2（地割れ）

地上で使える。全体で約2.1秒。自分のまわりを広く攻撃する。押してから約0.4秒で剣が刺さり、約1秒で地割れが噴き上がる。

1. 剣を逆手に持ち替えながら跳び上がり、切っ先を真下にして両手で頭上に掲げる。頂点で一瞬ためる
2. 全体重を乗せて落ち、片膝をつきながら突き立てる。そのまま肩を入れて、鍔の近くまで押し込む
3. 刺した瞬間から放射状のひびが伸びて光り、地鳴りが強くなる（約0.5秒）
4. 解放。ひび全体が白く光って光の柱が噴き上がり、地面がめくれ上がる。範囲内の相手を外へ一番強く吹き飛ばす
5. 剣を引き抜いて立ち上がる

当てた相手は気絶する（4秒）。

範囲は刺した地点から半径24（身長が約5の単位。叩きつけの約1.7倍）。発動中は操作できない。
途中で攻撃を受けると中断され、クールタイムに入る。各段階の長さ・範囲・クールタイムは `Controller.js` の `SKILL2` で設定。

### 移動しながらの通常攻撃

移動入力があるあいだは、通常攻撃で止まらない。歩き・走りの速さのまま動き続け、斬る向きは今キャラが向いている方向で決まる
（相手への自動の向き直りや、踏み込みでの前進はしない）。止まっているときの攻撃は、これまでどおり近くの相手へ向き直って踏み込む。

移動しながらの攻撃では、上半身は攻撃の振りのまま、腰から下を歩き・走りのサイクルに切り替える（`Animator.js` の `blendLocomotion`）。
腰の向きが変わる分は胸で打ち消すので、上半身の向きは攻撃モーションで作ったとおりに保たれる。足が滑って見えず、攻撃なしで歩く・走るときと同じ足の運びになる。

### 手応えの演出（`src/camera/CameraFx.js` ほか）

| 場面 | 演出 |
| --- | --- |
| 振った瞬間 | 斬る方向へカメラが振られ、画面が少し傾き、視野が一瞬広がる |
| 振った瞬間（見た目） | 振った向きの三日月形の斬撃波が前へ飛ぶ（当たり判定はなし） |
| 命中 | 時間がほぼ止まる（ヒットストップ）、画面揺れ、視野がぐっと寄る、相手が白く光る、星形の閃光、斬った向きに走る光の線、金色と水色の火花、のけぞりと吹き飛び |
| 空中攻撃 | 突っ込む勢いで視野が広がり、着地で地面のへこみ・ひび・隆起、範囲いっぱいに広がる3重の衝撃波の輪、閃光・土煙・強い揺れ |
| 3撃目 | 跳び上がりでカメラが引き、着地で揺れ、地面に衝撃波の輪と土煙。命中時の演出はすべて強め |
| 攻撃中 | 狙っている相手が画面に収まるよう、カメラが背後へゆっくり回り込む（`main.js` の `ATTACK_ALIGN_RATE`、0 で無効） |
| 常時 | カメラは P1 を少し遅れて追う（踏み込みや走りの勢いが出る） |

カメラ演出は追従カメラが決めた位置に描画の直前だけ上乗せして、描画後に元へ戻している。斬る方向は毎回カメラから見た向きに直すので、どの角度から見ていても斬撃の向きへ画面が振れる。

テクスチャ画像は使わず、単色のマテリアルだけで構成（ロブロックス風）。
石の配置は `seed` で決まるので、同じシードなら毎回同じ壁になる。
