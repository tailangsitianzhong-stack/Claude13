# Block Fighter（仮）

ロブロックス風の低コストテクスチャで作る格闘ゲームの土台。

## 起動

```bash
npm install
npm run dev
```

## 現在の内容: ステージ土台

- **草原の床**: 64×64 の島（上面 y=0）。上面は緑、側面は土色の単色
- **石の壁**: 外周に、大きさ・向き・傾きがバラバラな石ブロックを重ねて積んだ乱雑な壁
- **海**: 外側一面の単色の平面

## キャラ

- 身長5（×scale 1.5）= 脚2 + 胴2 + 頭1.2。すべて単色の箱
- 顔は透過キャンバスに描いた絵を頭の正面に1枚貼るだけ（`smile` / `angry`）
- 髪型は箱の組み合わせ（`short` / `spiky` / `none`）
- 肩・股関節・首に pivot があり、`joints.leftArm.rotation.x` などで動かせる

テクスチャ画像は使わず、単色のマテリアルだけで構成（ロブロックス風）。
石の配置は `seed` で決まるので、同じシードなら毎回同じ壁になる。

| ファイル | 役割 |
| --- | --- |
| `src/stage/config.js` | 床サイズ・壁の太さ/高さ・海面・色などの設定 |
| `src/stage/Stage.js` | ステージ組み立て。`bounds`（壁の内側の移動範囲）を返す |
| `src/character/Character.js` | キャラ生成（箱の体・関節・髪型・待機モーション） |
| `src/character/face.js` | 顔デカール（キャンバスに描いた絵を頭に貼る） |
| `src/main.js` | レンダラー・カメラ・ライト・ループ |
