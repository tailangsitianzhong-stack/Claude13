# Block Fighter（仮）

ロブロックス風の低コストテクスチャで作る格闘ゲームの土台。

## 起動

```bash
npm install
npm run dev
```

## 現在の内容: ステージ土台

- **草原の床**: 16×16 ブロックの島（上面 y=0）。側面は土＋草のフチ
- **石ブロックの壁**: 外周1列を石ブロックのみで3段＋胸壁（1つおきに1段）
- **海**: 外側一面。低ポリの波がゆれ、テクスチャがゆっくり流れる

テクスチャは画像ファイルを使わず、16×16px をキャンバスで生成して
`NearestFilter` で拡大（ドット感のある低コスト表現）。

| ファイル | 役割 |
| --- | --- |
| `src/stage/config.js` | 床サイズ・壁の高さ・海面などの設定 |
| `src/stage/textures.js` | 草・土・石・水のテクスチャ生成 |
| `src/stage/Stage.js` | ステージ組み立て。`bounds`（壁の内側の移動範囲）を返す |
| `src/main.js` | レンダラー・カメラ・ライト・ループ |
