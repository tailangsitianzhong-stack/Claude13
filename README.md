# Block Fighter（仮）

ロブロックス風の低コストテクスチャで作る格闘ゲームの土台。

## 起動

```bash
npm install
npm run dev
```

## 現在の内容: ステージ土台

- **草原の床**: 64×64 の島（上面 y=0）。上面は緑、側面は土色の単色
- **石の壁**: 外周に、大きさ・向き・傾きがバラバラな石ブロックを重ねて積んだ乱雑な壁
- **海**: 外側一面の単色の平面

### 公開（GitHub Pages など）

ビルドなしで、リポジトリの中身をそのまま配信しても動く。`index.html` が同梱の
`vendor/three.module.min.js` を import map で読み込むため（Safari は 16.4 以降）。
`npm run build` した `dist` を配信してもよい。

## 闘技場の壁

壁の石は傾けて乱雑に積んでいるため、そのままだと内側へ張り出してキャラやカメラが石に入る。
そこで、各石の内側の面が `wallInner`（床の端から壁の厚み分だけ内側）より内へ入らないよう、積んだあとに外へずらしている（`Stage.js`）。
キャラが動ける範囲（`bounds`）は、石の内側の面より手前に収まる。

## 視点

三人称の追従カメラ（`src/camera/ThirdPersonCamera.js`）。キャラの後方・頭より少し上から背中越しに見る。

- 視点と移動は分離: 移動してもカメラの向きは変わらず、視点操作でキャラは動かない
- 移動は視点の向きが基準（前に倒すと画面の奥へ進み、キャラはその方向を向く）
- カメラは、注視点から後ろへ伸ばした「腕」を縮めて、壁の内側の面（`stage.cameraBounds`）の手前に収める。壁際でカメラが石に入ったり、キャラの頭に押し込まれたりしない
- 距離・高さ・見下ろす角度・追従の遅れは同ファイルの先頭で調整できる

## キャラ

- すべて単色の箱。肌は白、体型は細身（胴幅1.6・腕0.6・脚0.72、身長 約4.95 × scale 0.15）
- 顔は透過キャンバスに描いた絵を頭の正面に1枚貼るだけ（`smile` / `angry`）
- 髪型は箱の組み合わせ（`short` / `spiky` / `none`）、袖は `short` / `long`
- 関節は首・腰・肩×2・肘×2・手首×2・股×2・膝×2・足首×2（＋骨盤の移動と回転）
- 曲げたときに隙間が開かないよう、子パーツを親の中へ少し伸ばしてある

### モーション

`src/character/poses.js` に、全関節の角度を返す関数として定義。

| 名前 | 内容 |
| --- | --- |
| `stand` | 立ちポーズ。呼吸、左右へのゆっくりした体重移動、視線の動き |
| `fight` | 構えポーズ。半身、前手と後手、後ろ足のかかとを浮かせて小さく弾む |
| `walk` | かかと着地 → 靴底を地面に → つま先で蹴り出し。骨盤と胸の逆ひねり、腕振り |
| `run` | 前傾、もも上げ、かかとの引きつけ、肘を曲げた腕振り、両足が浮く滞空 |
| `crouch` → `air` → `land` | ジャンプ。ため → 伸び上がり → 頂点で膝を抱える → 足を伸ばして落下 → 沈み込んで着地 |

| `attack1` → `attack2` → `attack3` | 剣の3連撃（ループ）。振りかぶり → 斬る瞬間 → 振り抜き → 残心 |
| `airSlam` | 空中攻撃。剣を頭上へ振りかぶり、切っ先を下にして前方へ突っ込む。着地後は `attack3` の着地〜残心へつながる |
| `grab` → `liftCrouch` → `carry` → `throw` | コンボ技の自分側。掴む → 沈み込んでためる → 掲げて跳ぶ → 振りかぶって投げ落とす |
| `struggle` → `thrown` → `down` | コンボ技の相手側。もがく（両手で相手の腕を掴み、足をばたつかせ、首を振り、体をよじる）→ 手足をばたつかせて落ちる → 倒れる |
| `brake` | 急停止。前足を突っ張り、腕を広げてバランスを取る |
| `spinUp` → `throwSword` → `beckon` → `flurry` → `pullOut` → `kick` | スキル1の自分側。振り回す → 投げる → かざして引く → 連打 → 引き抜く → 蹴る |
| `impaled` → `dragged` → `pummeled` | スキル1の相手側。刺さってよろめく → 引きずられる → 連打を浴びる |
| `ultDraw` → `ultThrow` | 必殺技。左手で小剣を取り出す → 投げる |
| `ultSummon` → `ultWindup` → `ultDash` → `ultFinish` | 必殺技のムービー。両手剣を構える → 構え直す → 斬り抜ける → 振り抜く |
| `ultLeap` → `ultLand` | 必殺技の締め。跳び上がる → 片膝をついて着地 |
| `chargeStance` | スキル3のため。剣を右脇に引いて構える（放つときは通常攻撃の振りを素早く使う） |
| `stunned` | 気絶。ふらふらと揺れ、首がぐらつき、膝が抜けかける |
| `lungeAim` → `lungeDash` → `lungeStrike` | スキル4。剣を前へ向けて構える → 水平に寝て飛びかかる → 突きの姿勢で止まる |
| `groundStab` → `stabCharge` → `stabPull` | スキル2。振り上げて突き刺す → 膝をついて力を込める → 引き抜いて立つ |
| `hit` | 被弾。のけぞって持ち直す |

- 歩き・走りの周期は移動距離に同期（足が滑って見えない）
- 接地中は靴底の位置から腰の高さを毎フレーム決める（足のめり込み・浮きを防ぐ）
- モーションの切り替えは今の姿勢からなめらかに補間
- 慣性の傾き: 走り出しは前のめり、止まるとのけぞって揺り戻し、曲がるときは内側へ倒れる（どのモーションにも重なる）
- 走りから入力を離すと、足を突っ張って少し滑ってから止まる（`brake`。足元に土煙）
- 攻撃・着地・急停止のあとは、ゆっくり構え直して少し揺り戻してから立ちに戻る

## 剣と攻撃

- 剣は箱と三角の切っ先だけの西洋剣（刃・樋・十字の鍔・革巻きの柄・柄頭）。右手首の関節に握らせている
- 剣を持っているときは、立ち・構え・歩き・走りで右腕の持ち方が変わる（`poses.js` の `carrySword`）
- 攻撃は `Controller.js` の `ATTACKS` で長さ・当たる区間・つなぎのタイミング・踏み込みを設定
- 攻撃を出した瞬間、近くの相手へ自動で向き直り、剣が届く間合いまで踏み込む
- 当たり判定は刃（根元〜先端）と相手の体の距離。振っている間は1フレームを5分割して取りこぼしを防ぐ
- 攻撃中は刃を包む光のオーラが剣より長く伸び、その先端までが攻撃範囲になる（`Sword.js` の `AURA.end`。剣だけのときの約1.5倍）
- 振っている間は剣の軌跡（水色の光の帯）が出る

### 空中攻撃（叩きつけ）

ジャンプ中に攻撃を押すと、前方斜め下へ一瞬（約0.1秒）で突っ込み、剣で地面を叩く。
入力していればその方向へ、近くに相手がいればその手前へ着地する。
着地した瞬間、剣が叩いた地点を中心とした円の中にいる相手に命中する範囲攻撃（強攻撃扱い）。
叩いた地面はへこんでひびが入り、まわりの地面がめくれ上がる（約2秒で元に戻る。見た目だけで床の形は変わらない）。
一度出すと、着地から0.8秒は出せない（クールタイム）。
突っ込む距離・速さ・範囲・クールタイムは `Controller.js` の `AIR_SLAM` で設定。着地後は攻撃を押し続けると地上の連続斬りへつながる。

### コンボ技（掴み上げ）

通常攻撃の3段目（跳び込み兜割り）を当てると、1秒だけ受け付ける。その間にジャンプを押すと発動。

1. 一瞬で間合いを詰め、左手で相手の胸ぐらを掴む（相手はもがき続ける）
2. 掴んだまま沈み込んで力をため、相手を掲げて身長の約3倍の高さまで跳び上がる
3. 頂点で相手を前方の地面へ投げ落とす（相手は背中から激突して倒れる）
4. 倒れた相手へ、剣で叩きつける（通常の叩きつけより強く吹き飛ばす）

発動中は操作できず、カメラは引いて2人を映す。受付時間・高さ・各段階の長さは `Controller.js` の `FINISHER` で設定。
時間切れ、または相手が離れすぎているときは、ただのジャンプになる。

### スキル1（剣投げ）

地上で使える。全体で約5秒（ヒットストップ込み）。押してから剣が刺さるまでは約0.7秒。

1. 剣を頭上で素早く振り回す
2. 相手へ投げる。剣は縦に回転しながら飛び、相手の胸に刺さる
3. 左手をかざすと光の綱がつながり、刺さった剣ごと相手を宙に引きずって手元へ引き寄せる
4. 両手で連打（毎秒 約7発、だんだん速く。計13発前後）。1発ごとに相手の頭と上体が弾かれる
5. 柄を握ってためてから、体をひねって剣を引き抜く
6. 右足で蹴り飛ばす（一番強い吹き飛ばし）

発動中は操作できない。相手が遠すぎる（身長の約9倍より先）ときは前方へ投げ、剣が回りながら手元に戻って終わる。
各段階の長さ・連打の速さ・クールタイムは `Controller.js` の `SKILL1` で設定。

### スキル3（ため斬り）

スキル1を使うと、同じボタンがスキル3に変わる（スキル3を使うとスキル1に戻る）。

- ボタンを押している間、剣を右脇に引いて構え、力をためる（最大2秒）。ためるほど深く沈み、剣の光が強くなる
- 途中で離すと、飛ぶ斬撃を1つ放つ。ためた分だけ斬撃が大きく、強くなる
- 最大までためると、自動で斬撃を3つ続けて放つ（袈裟・横・縦。3つ目が一番強い）
- ため中は移動できないが、向きは変えられる。近くに相手がいれば自動でそちらを向く

斬撃は身長の約27倍先まで飛び（闘技場の端まで届く）、見た目の大きさと当たり判定は初期の3倍。ためる時間・速さ・距離・大きさは `Controller.js` の `SKILL3` で設定。

### スキル4（突進）

スキル2を使い終えると、スキル2のボタンがスキル4に変わる（使うとスキル2に戻る。スキル3と同じ仕組み）。
地上で使える。全体で約1.1秒。

1. 剣を相手へまっすぐ向けて、体を低く沈めて構える（約0.3秒。この間も相手を狙い続ける）
2. 一瞬（約0.09秒）で飛びかかる。相手がいれば、その手前まで（最大で身長の約12倍）。通り道に光の線と火花が走る
3. 突きの姿勢で止まり、命中すると相手を遠くまで吹き飛ばす（約45〜50リグ = 身長の約10倍）。相手は背中から飛び、倒れたまま滑る
4. 構え直す

相手が闘技場の壁に当たると、激突の演出が出る。
カメラは相手の方へ動かない。飛びかかっている間は追従を止め、終わってからゆっくり自分に追いつく。
各段階の長さ・距離・吹き飛ばす強さは `Controller.js` の `SKILL4` で設定。

### 状態異常（気絶）

状態異常は `src/character/StatusEffects.js` の「枠」で管理する。キャラごとに1つ持ち、種類ごとに残り時間を数える。
新しい状態異常は `STATUS_DEFS` に1行足し、効果の中身を `has(name)` で判定して作る。表示枠（`src/ui/StatusHud.js`）は自動で対応する。

- **気絶**（`stun`）: スキル2を当てた相手に4秒付く。その間は何も入力できず、ふらふら立ったまま（`stunned` ポーズ）、頭上を星が回る
- 相手にかかっている状態異常は、画面上部の中央に「種類・残り時間バー・残り秒数」で表示する

### スキル2（地割れ）

地上で使える。全体で約2.1秒。自分のまわりを広く攻撃する。押してから約0.4秒で剣が刺さり、約1秒で地割れが噴き上がる。

1. 剣を逆手に持ち替えながら跳び上がり、切っ先を真下にして両手で頭上に掲げる。頂点で一瞬ためる
2. 全体重を乗せて落ち、片膝をつきながら突き立てる。そのまま肩を入れて、鍔の近くまで押し込む
3. 刺した瞬間から放射状のひびが伸びて光り、地鳴りが強くなる（約0.5秒）
4. 解放。ひび全体が白く光って光の柱が噴き上がり、地面がめくれ上がる。範囲内の相手を外へ一番強く吹き飛ばす
5. 剣を引き抜いて立ち上がる

当てた相手は気絶する（4秒）。

範囲は刺した地点から半径24（身長が約5の単位。叩きつけの約1.7倍）。発動中は操作できない。
途中で攻撃を受けると中断され、クールタイムに入る。各段階の長さ・範囲・クールタイムは `Controller.js` の `SKILL2` で設定。

### 移動しながらの通常攻撃

移動入力があるあいだは、通常攻撃で止まらない。歩き・走りの速さのまま動き続け、斬る向きは今キャラが向いている方向で決まる
（相手への自動の向き直りや、踏み込みでの前進はしない）。止まっているときの攻撃は、これまでどおり近くの相手へ向き直って踏み込む。

移動しながらの攻撃では、上半身は攻撃の振りのまま、腰から下を歩き・走りのサイクルに切り替える（`Animator.js` の `blendLocomotion`）。
腰の向きが変わる分は胸で打ち消すので、上半身の向きは攻撃モーションで作ったとおりに保たれる。足が滑って見えず、攻撃なしで歩く・走るときと同じ足の運びになる。

### スタート画面とロード

起動すると、まず**スタート画面**（`index.html` の `#boot`。JS の読み込みより先に出る）。「START」（画面のどこでもタップ）を押すと**ロード画面**になり、進み具合（%）が出る。終わると武器選択へ進む。

ロードでやること（`src/main.js` の `loadAll` / `warmRender`）:
- あとで作ると重くなるものを、先に全部作る（吸血牙の分身・巨大蝙蝠・足の蝙蝠・宝石、矢印の砲弾など）
- すべての見た目（試合のステージ・バッティングセンター・ドラキュラ城・ゴミ処理場・全エフェクト）を、画面の外のものまで一度描いて、**シェーダーのコンパイルと、形・画像の転送を済ませる**。試合中に初めての技や必殺技を出しても、止まらない
- 光源の数が変わると、画面のすべての物のシェーダーが作り直されて止まるので、**試合中に光源を増やさない**（赤い宝石の PointLight は外した。ムービーの舞台の光源は、舞台ごとに数が決まっていて、ロードで先に作る）

確認: 4つの武器すべてで、通常攻撃・スキル1〜4・コンボ・必殺技を通して出して、新しいシェーダーが**0個**（ロードだけで済んでいる）ことを `renderer.info.programs` の数で確かめた。
確認用に、`?skipboot` を付けて開く（または `game.start('武器')`）と、スタート画面とロードを飛ばす。

### エラーが出ても止まらない（固まり対策）

three の描画ループは、コールバックが例外を出すと、次のコマを予約せず、**画面が最後のコマのまま固まる**。そのため `src/main.js` で、
- 1コマの処理（`step`）を try/catch で囲み、例外が出てもループを続ける（そのコマは、とにかく描画する）
- 演出の更新（各ディレクター）と、攻撃の演出イベントは、それぞれ個別に囲み、演出の例外でゲームの進行（ダメージ・状態）や描画を止めない
- 例外は、画面の下に赤い帯で出す（タップで閉じる。同じ内容は1回だけ）。`window.game.reportError` から

固まったときは、赤い帯の文章を教えてもらえれば、原因をたどれる。

実際に起きた原因: 矢印のコンボ（地面を隆起）の更新が、基底クラスの `updateFinisher`（剣のつかみ技）と**同じ名前**で、基底の更新から意図せず呼ばれ、`this.bs` が空で例外 → ループが止まって固まった（攻撃ボタンを押しっぱなしで、次の1段目の途中にジャンプボタンを押したとき）。矢印側の名前を `updateArrowFinisher` に変え、基底の `startFinisher` だけを上書きして、どの状態からでもコンボが出るようにした。サブクラスにメソッドを足すときは、基底クラスと名前がかぶらないか注意（かぶりは、起動時に一覧で確認できる）。

### 武器選択

試合の前に、武器選択画面が出る（`src/ui/WeaponSelect.js`）。決定ボタン（PC は Enter / Space）で試合が始まる。画面が低いときは、**上下にスライド**（スワイプ・ホイール。ページ全体は `touch-action: none` なので、この画面と、その中の全要素に `pan-y` を指定している）して、全部の武器と決定ボタンを見られる。スライドしたときは武器を選ばず、タップしたときだけ選ぶ。選んだ武器は `window.game.weapon` に入る。

**現在選べる武器は「剣」「バット」「吸血牙」「矢印」。ほかの武器は、あとから追加していく予定**（まだ追加しない）。
武器の一覧は `src/game/weapons.js` の `WEAPONS` にあり、ここに1件足すと選択画面にカードが自動で並ぶ。
武器を足すときは、武器ごとのモデル・モーション・技・コントローラ（`BatController` のように、`CharacterController` を継承して通常攻撃・スキル・必殺技を差し替える）も用意する。

### バット

武器選択で「バット」を選ぶと使える。移動・ジャンプ・HP・ゲージなどの共通部分は剣と同じで、攻撃・スキル・必殺技がバット用になる（`src/character/BatController.js`）。
**ジャンプ中の攻撃はない**。通常攻撃3段目のあとの「掴み上げ」コンボもない。

**通常攻撃（3段）**: 横殴り → 一回転して振り回す → ボールを放り上げて打ち、遠距離から当てる（3段目は近接判定なし。ボールが飛ぶ）

| ボタン | 内容 |
| --- | --- |
| スキル1 | バットを金属にして強いボールを打ち、遠距離を攻撃。そのあと、バットは木に戻る。使うとスキル3に切り替わる |
| スキル3（スキル1のあと） | ボールを5発続けて打つ |
| スキル2 | 近くの敵にバットを投げつけ、ダッシュして殴りまくり（7発）、最後の一撃で遠くへ吹き飛ばす。バットは手元に戻る。使うとスキル4に切り替わる |
| スキル4（スキル2のあと） | バットを空中へ投げて回し続け、敵をパンチ（5発）。そのあと跳び上がってバットをつかみ、敵に叩きつける |
| 必殺技 | 懐から鉄球を取り出して当てる → 画面が切り替わり、バッティングセンターのムービー。ふらふらの敵に、ピッチングマシンから飛んでくるボールを8球打ち返して当てまくる（最後の一球はスローモーションで、敵を吹き飛ばす）。ムービーが終わると元の画面に戻る |

**野球のフォームを全身で表現**（`src/character/poses.js` の「バット用のポーズ」）: 打撃は「構え（バットをゆらす）→ため（体重を後ろ足へ、前足を上げる）→ 踏み込み → **腰が先に回り、肩・腕・バットが遅れて続く** → 打撃（後ろ足はつま先立ち）→ フォロースルー（バットが肩へ巻き込む）」。
スキル1は予告ホームランの構え → ボールを放って打つ、スキル3は左手で軽く放ってコンパクトに連打、スキル2は投球フォーム（脚上げ → 踏み込み → 腕を引く → 腰の回転から腕を振る → リリース）→ ダッシュ → 腰の回転で打つ大振りパンチ → バットをキャッチ、スキル4はバットフリップ（沈んでから跳びながら放る）→ 跳び上がって全身で叩きつけ、必殺技は懐から鉄球を抜き、左腕の投球フォームで投げる。ムービーの打撃も同じフォーム（交互に強打）。

**風**: 通常攻撃で振るとき、バットの先の速さ（振りの強さ）に応じた白い風が起こる。風が刃を押し広げるので、**当たる範囲は約2倍**（弱い振りで約1.6倍、強い振りで約2.4倍。実測では、近接の当たりが届く距離が約1.5 → 約2.7〜3）。命中すると足もとに風圧の輪と土ぼこりが出て、振りが強いほど大きい。調整は `src/main.js` の `WIND_REF`（最大の強さになる速さ）と `WIND_EXTEND`（押し広げる長さ）。

飛行するボール・命中の演出は `src/game/BatDirector.js`、必殺技のムービーは `src/cinematic/BatUltimate.js`（舞台は `BattingCenter.js`）。
ダメージは `Health.js` の `DAMAGE`、スキルの長さ・距離は `BatController.js` の `BSKILL1〜4`・`ULTB` で設定。

### 吸血牙

武器選択で「吸血牙」を選ぶと使える。両手に爪、口に牙が付く。共通部分は剣と同じで、攻撃・スキル・必殺技が吸血牙用になる（`src/character/FangController.js`）。

**通常攻撃（3段）**: ① 前方向への噛みつき（大きな牙のあごがガブッと閉じる）→ ② 爪での斜め薙ぎ払い（赤い三日月）→ ③ 首に噛みつき、つかんだまま肉を引きちぎる（血しぶき。3段目のあとの「掴み上げ」コンボはない）。噛みつきは爪ではなく、正面の近くにいる相手に当たる。

**斬撃をまとう**: 通常攻撃の間、爪から赤い斬撃のオーラが長くのびる（軌跡も当たり判定もそこまで届く）。爪の太さの判定も2倍。噛みつきの届く距離も約2倍で、首への噛みつきは遠くからでも相手をすばやく引き寄せる（実測: 噛みつき 約1.2 → 約2.6、爪 約1.0 → 約2.2）。

**ジャンプ攻撃**: 空中で攻撃ボタン。前方へ小さなかぎ爪を3つ飛ばす（射程は短い。叩きつけはない）。

| ボタン | 内容 |
| --- | --- |
| スキル1 | 爪を赤く染め、薙ぎ払いで赤い大きな斬撃を前へ3つ高速で飛ばす（斬撃は大きく、当たる幅も約2.4倍）。**当たるたびに自分の体力が回復**（1発14。緑の「+14」が出る）。使うとスキル3に切り替わる |
| スキル3（スキル1のあと） | 蝙蝠の大群になって弾け、小さな分身4体が相手を囲んで、順番にすばやく爪で攻撃する（全体で約1.8秒）。終わると蝙蝠になって本体へ戻る |
| スキル2 | すぐに巨大蝙蝠になって前へ高速で突進（出から約0.2秒で当たり、全体で約0.6秒。当たると相手を遠くへ吹き飛ばす）。使うとスキル4に切り替わる |
| スキル4（スキル2のあと） | 足だけを蝙蝠にして宙に浮き、腕を広げて回転しながら薙ぎ払う（4回。最後の1回で吹き飛ばす） |
| 必殺技 | 赤い宝石を投げつける → 当たると画面が切り替わり、**ドラキュラ城**のムービー。ここはどこだとあたふたする敵のところへ、蝙蝠の大群が一つにまとまって本体が現れる → 赤い宝石が光ると凶暴化 → **重い牙の一撃**（大ダメージ）で、**最大HPの30%を回復**。ムービーが終わると元の画面に戻る |

スキルの途中で被弾すると、変身（蝙蝠・分身・足の蝙蝠・赤い爪）は元に戻る。
蝙蝠の大群は1つの InstancedMesh（頂点シェーダではばたき）で動かしているので、数百匹でも軽い（`src/character/FangBats.js`）。
演出は `src/game/FangDirector.js`（赤い斬撃・あご・血しぶき・吸血）、必殺技のムービーは `src/cinematic/FangUltimate.js`（舞台は `DraculaCastle.js`）。
ダメージ・回復量は `Health.js` の `DAMAGE`（`fang*`）、スキルの長さ・距離は `FangController.js` の `FSKILL1〜4`・`ULTF` で設定。

### 矢印

武器選択で「矢印」を選ぶと使える。素手に、色つきの矢印のステッカーを貼って戦う（`src/character/ArrowController.js`）。ジャンプ中の攻撃はない。

| 矢印 | 色 | 使いどころ |
| --- | --- | --- |
| 加速 | 黄 | 右腕に貼る（通常1段目）/ 床に貼る（通常2段目・スキル3） |
| 砲弾 | 橙 | スキル1: 立体の大きな矢印を高速で飛ばす |
| 上向き | 緑 | 足に貼る（スキル2）/ 地面に貼る（コンボ） |
| 下向き | 紫 | 相手に貼って地面に押さえつける（通常3段目） |
| 鈍足 | 青 | スキル4: 相手の移動速度を50%に（5秒） |
| 前向き | 水色 | 必殺技: 自分の頭の上に貼る |
| 引き寄せ | 赤紫 | 必殺技: 相手に貼ると、ゴミが引き寄せられる |

矢印はすべて、先が**前（技の向き）**を向く（床の矢印・砲弾・必殺技の前向き矢印・鈍足矢印の弾）。上向き・下向きの矢印だけは、足・地面・相手の胸で上や下を向く。

**通常攻撃（3段）**: ① 右腕に加速の矢印を貼って、全体重の右ストレート（相手を遠くへ**吹っ飛ばす**）→ ② 床に加速の矢印を貼り、**猛ダッシュ**で相手へ向かって飛び蹴り → ③ 相手に**下向き矢印**を貼って地面に押さえつけ（相手はぺしゃんこ）、6連続パンチ。
**コンボ**: 3段目の連打が終わると、少しの間（1秒）ジャンプボタンが切り替わる。押すと、地面に上向き矢印を貼って**地面を隆起**させ、範囲攻撃で相手を高く打ち上げる。

| ボタン | 内容 |
| --- | --- |
| スキル1 | 砲弾の矢印（大きなオレンジの立体の矢印。鼻先を上げて頭の上に構え、撃つと炎をひいてゆっくり→一気に加速して飛ぶ）を貼って、高速で飛ばす（命中で大爆発。相手を吹き飛ばす）。使うとスキル3に切り替わる |
| スキル3（スキル1のあと） | 相手までの道のりの床に加速の矢印を並べて、猛ダッシュで蹴る。**相手との距離が遠いほど、加速が速く、ダメージが高い**（ダメージ = 40 + 距離×2.4、最大230。リグ単位の距離） |
| スキル2 | 足に上向き矢印を貼って**高く飛び**、地面（相手の手前）へ叩きつける。範囲攻撃。使うとスキル4に切り替わる |
| スキル4（スキル2のあと） | 相手に鈍足矢印を貼る。**相手の移動速度が50%**になる（5秒間。状態異常の枠に「鈍足」が出て、残り時間が見える。全キャラ共通の効果で、`Controller.js` の移動速度に掛けている） |
| 必殺技 | 自分の頭の上に前向き矢印を貼り、人間砲弾のように突撃 → 当たると画面が切り替わり、**ゴミ処理場**のムービー。相手に引き寄せ矢印を貼ると、小さなゴミ → ドラム缶・洗濯機 → 冷蔵庫・車と、**大きなゴミが次々に引き寄せられて**相手に命中し、最後は大きな車で押しつぶす。終わると元の画面に戻る |

スキルの途中で被弾すると、貼った矢印・押さえつけ・相手のつぶれ具合は元に戻る。
ゴミの位置は、ムービーの時刻から計算している（予定表 `junkSchedule()` をコントローラ（ダメージ）と演出（位置）が共有）。
演出は `src/game/ArrowDirector.js`（ステッカー・砲弾・隆起・ダッシュの軌跡）、必殺技のムービーは `src/cinematic/ArrowUltimate.js`（舞台は `JunkYard.js`）。モデルは `src/character/Arrow.js`。
ダメージは `Health.js` の `DAMAGE`（`arrow*`）、スキルの長さ・距離は `ArrowController.js` の `ASKILL1〜4`・`AFIN`・`ULTA` で設定。

### HP と必殺技ゲージ

- 画面上部に自分の HP バー。減った分は黄色いバーがあとから追いかける。HP が3割を切ると赤くなる。**相手の HP は表示しない**（内部では数えていて、KO や必殺技の判定に使う）
- 攻撃を当てると、与えたダメージの12%、スキルを使うと1回ごとに10、必殺技ゲージが溜まる（満タン100。必殺技の最中は溜まらない）
- ダメージは当たった場所に数字で出る（大きいダメージほど大きく、色が変わる）
- 相手の HP が0になると KO。相手は吹き飛んで気絶し、約3秒後に HP が全回復して再開する
- ダメージ量・ゲージの溜まり方は `src/character/Health.js` の `DAMAGE` と `FIGHT` で設定

### 必殺技「無影千刃斬」

ゲージが満タンになると、ジャンプボタンの左にボタンが出る（PC は T / G。画面にも案内が出る）。全体で約9秒。

1. **小剣を投げる**: 左手で腰の後ろから小剣を取り出し、相手へ投げつける（闘技場のどこにいても届く）。小剣は、相手の胸の正面に水平に刺さる（相手の向きや姿勢によらず、毎回同じ位置）
2. **命中で画面が切り替わる**: 小剣が刺さると時間が止まり、白い閃光とともに、暗い舞台のムービーへ。自分も相手も舞台へ移り、ボタンやHPの表示は隠れて上下に黒帯が出る
3. **両手剣**: 小剣が消えて両手剣が現れ、技の名前が出る
4. **斬りまくり**: 自分は一瞬で別の場所へ移っては、縦・横・斜めに相手を斬り抜ける（11回。通り道に光の線が残る）。カメラは2回斬るごとにカットが切り替わる（周回・俯瞰・あおり・追尾・寄り）
5. **締め**: 高く跳び上がり、スローモーションでため、相手を叩き落とす一撃
6. **元の画面へ戻る**: 閃光とともに、自分も相手も、必殺技を出した位置の元の画面に戻る。相手は倒れていて、しばらくして起き上がる

ムービーの進行・斬撃の通り道・舞台の中心は `Controller.js` の `ULT`、カメラワークと演出は `src/cinematic/UltimateDirector.js` で設定。
